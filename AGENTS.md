# Repository Instructions

## Generated app skills

`app-skills/` is generated by the upstream connector pipeline. Do not create, edit, restore, or delete files under `app-skills/` in this repository.

For a provider-specific correction or enhancement, open an issue in this repository with the provider name, current behavior, expected behavior, and supporting public documentation. Maintainers will apply accepted changes in the source repository and synchronize the generated result here.

Only the synchronization PR created by `oomol-bot` from this repository's `bot/sync-app-skills` branch may modify `app-skills/`. The required `Protect generated app-skills` check rejects every other PR that changes the generated tree.

Files outside `app-skills/`, including publishing workflows and `contrib/`, remain maintained in this repository.
